# Чат

Чат на сервере связан между **миром ферм** и **миром построек**.

---

## Типы сообщений

| Префикс | Описание |
| :--- | :--- |
| `!` | Глобальное сообщение — видно на всех серверах |
| `#` | Торговый чат — для объявлений о покупке/продаже |
| `@никнейм` | Упоминание игрока (как в Discord) |

---

## Специальные теги

В сообщениях можно использовать теги для отображения информации:

| Тег | Что показывает |
| :--- | :--- |
| `[ec]` | Содержимое эндер-сундука |
| `[inv]` | Ваш инвентарь |
| `[hp]` | Количество здоровья |
| `[ping]` | Ваш пинг |
