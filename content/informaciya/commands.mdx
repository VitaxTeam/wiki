# Команды

## Команды для всех игроков

| Команда         | Обозначение                                                                   |
| --------------- | ----------------------------------------------------------------------------- |
| /sit            | Позволяет сесть.                                                              |
| /lay            | Позволяет лечь.                                                               |
| /crawl          | Позволяет ползти                                                              |
| /hub            | Позволяет переместиться в лобби.                                              |
| /noai           | Отключает ИИ у жителей.                                                       |
| /ai             | Включает ИИ у жителей.                                                        |
| /pp toggle      | Отключает визуальное отображение частиц у себя и спонсоров                    |
| /skin           | Позволяет поставить скин по URL или по лицензионному аккаунту.                |
| /me             | РП-команда                                                                    |
| /try            | РП-команда                                                                    |
| /do             | РП-команда                                                                    |
| /sex            | Позволяет заняться любовью                                                    |
| /лицензии       | Открывается меню лицензий                                                     |
| /profile        | Открывается меню профиля                                                      |
| /rpsign         | Позволяет сделать рп-табличку                                                 |
| /reply          | Быстро ответить в личных сообщениях                                           |
| /warns          | Посмотреть свои варны                                                         |
| /vrc            | Переподключиться к войсчату                                                   |
| /ignore         | Начать игнорировать сообщения от определённого человека                       |
| /groups         | Создать группу в плазмовойсе                                                  |
| /bellyflop      | Начать крутиться, как на трезубце                                             |
| /msg,pm,tell    | Отправить сообщение человеку                                                  |
| /changepassword | Можете изменить свой пароль                                                   |
| /premium        | Позволяет сделать аккаунт только лицензионным(больше не нужно вводить пароль) |
| /addsocial      | Привязать социальную сеть                                                     |
