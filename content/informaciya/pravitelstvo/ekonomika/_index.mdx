# Экономика

### **Экономика** - структура, которая контролирует экономическое положение сервера.

Экономика работает по **системе лицензий**. Лицензии выдаются по категориям товаров, которые продает игрок. **У каждой категории - своя цена лицензии.** Лицензия выдается на срок в **20 дней**. По истечении лицензии игрок не имеет права продавать товар, иначе будет выдан штраф по [законодательству сервера](/informaciya/pravitelstvo/zakonodatelstvo).

---

| Категория товаров                | Цена лицензии |
| :------------------------------- | :------------ |
| Строительные блоки               | **10 АР**     |
| Броня и оружие                   | **20 АР**     |
| Инструменты                      | **20 АР**     |
| Еда                              | **15 АР**     |
| Тотем бессмертия и зелья         | **15 АР**     |
| Алкогольные напитки              | **20 АР**     |
| Драгоценные ресурсы и расходники | **20 АР**     |
| Азартная организация             | **64 АР**     |

---

<Hint type="info">
  **Лицензию необходимо хранить в рамке в месте продажи!** Лицензия является
  государственной собственностью!
</Hint>

---

### Должности в структуре:

1.  **Глава экономики** - руководитель структуры, член совета, глава государственной казны, а также государственного банка. Ответственный за экономическое состояние всего севера.
2.  **Банкир** - имеет доступ к карточкам, может пополнять и снимать АРы с вашего счета. Имеет право выдавать лицензии на бизнес.
3.  **Налоговый инспектор** - следит за налогообложением магазинов, ведет налоговый учет, имеет право на проверку лицензий на бизнес.
