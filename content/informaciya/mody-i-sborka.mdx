## Сборка от нашего администратора!

Если вы не хотите собирать сборку самостоятельно - вы можете скачать сборку от нашего администратора! В сборке есть много различных модов на визуал и оптимизацию.

[**[СКАЧАТЬ]**](https://modrinth.com/modpack/vanillapackofficial)

## Обязательны к установке:

| Модификация                                             | Описание                                                                                           |
| :------------------------------------------------------ | :------------------------------------------------------------------------------------------------- |
| [Fabric API](https://modrinth.com/mod/fabric-api)       | Необходимый мод для работы модификаций.                                                            |
| [PlasmoVoice](https://modrinth.com/plugin/plasmo-voice) | Мод, который позволяет использовать голосовой чат, использовать музыку и многое другое на сервере. |
| [EmoteCraft](https://modrinth.com/plugin/emotecraft)    | Мод, который позволяет использовать эмоции на сервере.                                             |

## Мы рекомендуем:

| Модификация                                              | Описание                                                                    |
| :------------------------------------------------------- | :-------------------------------------------------------------------------- |
| [Sodium](https://modrinth.com/mod/sodium)                | Оптимизация графики, повышает FPS в Minecraft за счёт улучшения рендеринга. |
| [Iris Shaders](https://modrinth.com/mod/iris)            | Позволяет использовать шейдеры в Minecraft на Fabric, аналогично OptiFine.  |
| [Sodium Extra](https://modrinth.com/mod/sodium-extra)    | Дополнение к Sodium, добавляет настройки графики и улучшения.               |
| [Mod Menu](https://modrinth.com/mod/modmenu)             | Добавляет меню для удобного управления и настройки модов в игре.            |
| [Lithium](https://modrinth.com/mod/lithium)              | Оптимизирует игровую логику, снижает лаги и улучшает производительность.    |
| [AppleSkin](https://modrinth.com/mod/appleskin)          | Показывает информацию о сытости и восстановлении здоровья от еды.           |
| [Entity Culling](https://modrinth.com/mod/entityculling) | Улучшает производительность, скрывая невидимые сущности.                    |
| [Flashback](https://modrinth.com/mod/flashback)          | Альтернатива ReplayMod.                                                     |
| [Dynamic FPS](https://modrinth.com/mod/dynamic-fps)      | Автоматически снижает FPS, когда игра неактивна, чтобы уменьшить нагрузку.  |
| [3D Skin Layers](https://modrinth.com/mod/3dskinlayers)  | Добавляет 3D-слои для скинов игроков, улучшая их внешний вид.               |
