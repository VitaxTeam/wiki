# Спонсорство

Если вы хотите сделать проект лучше - вы можете приобрести спонсорскую подписку. Подписка не даёт особых преимуществ над другими игроками.

## Спонсор **ВИТАКС**

| Возможность | Описание |
| :--- | :--- |
| `/disc burn` | Возможность создавать пластинки с уникальной музыкой |
| `/kuni` | Возможность стать КУНИменом |
| `/blowjob` | Предложить сделать м*нет |
| `/pp` | Возможность включить партиклы вокруг себя. Доступно 33% |
| `/playertimetop` | Возможность посмотреть топ по наигранному времени |
| Банк | Возможность создавать дополнительные карты в банке (Доступно при полном запуске функционала сайта) |
| Чат | Возможность форматировать текст в чате, используя [MiniMessage](https://webui.advntr.dev/) |
| Discord | Особая роль в DISCORD |
| Таб / Чат | Особый префикс |

*   Месяц - `249₽`
*   3 Месяца - `555₽`
*   Сезон - `711₽`
