# Администрация

Администрация — это **НОН-РП орган**, который занимается техническим управлением проекта.

---

## Обязанности администрации

- Управление сервером
- Наказание нарушителей правил
- Поддержание порядка
- Решение технических проблем

---

## Уровни администрации

| Уровень | Описание |
| :--- | :--- |
| **Высшая администрация** | Имеют роль «Администратор» в Discord, максимальные полномочия |
| **Обычная администрация** | Модераторы и помощники с ограниченными полномочиями |

<Hint type="info">
Администрация не участвует в РП-составляющей сервера — для этого есть [Правительство](/informaciya/pravitelstvo).
</Hint>
